# 记忆机制 · 人怎么用

> **这份是给人类方看的。**
> 只回答一个问题：想让某个机制发生，该说什么话。
> 机制本身怎么写、Agent 那边怎么做，在 `规则_通用.md` 和 `AgentID_怎么用.md` 里。

---

## 一、说什么，触发什么

| 你想要 | 说这句 | 实际发生 |
|---|---|---|
| 让她把今天记下来 | 「把今天记一下」／「该总结了」 | 写日摘要 → 落盘 → 锚点前移 |
| 让她整理过去这段时间 | 「处理你自身记忆」 | 上次总结到现在的上下文切成事件碎片，然后洗牌升降级 |
| 让她记住这一件事 | 「这条记住：……」 | 写一条事件碎片，进 L0 |
| 让她别再用这个 | 「这条以后别提了」 | 降到半丢弃（不删，除非你说删） |
| 让她翻很早以前的事 | 「翻翻很久以前的」／「用半丢弃里的」 | 才允许动半丢弃层 |
| 让她确认记得对不对 | 「你还记得……吗」 | 直接检索，L0~L1 找不到会下探 |
| 让她顺着一条往下想 | 「从……那条往下牵」 | 关联联想，受权重额度限制 |
| 让她别查了，就聊 | 「别翻库，就说话」 | 不调用检索 |

**含糊的请求会得到含糊的结果。** 「整理一下」她可能只写摘要；要动事件碎片，说「处理你自身记忆」这个明确的词。

## 二、不想靠 Agent 时，自己敲命令

工具在 `memory/mem.js`，用 node 跑。

```bash
node mem.js ctx                          # 生成当前上下文（摘要 + 最近 300 条）
node mem.js ev list                      # 看所有事件碎片，按层级
node mem.js ev list --level L2           # 只看 L2
node mem.js ev search 配音               # 直接检索
node mem.js ev link 配音做到95%           # 从一条往下牵（受权重额度限制）
node mem.js ev show 配音做到95%           # 看一条的完整内容
node mem.js ev add 新事件.json            # 手工加一条（进 L0）
node mem.js ev summarize                 # 洗牌：升降级
node mem.js sum tree                     # 看摘要树
node mem.js sum anchor                   # 看摘要锚点停在哪一轮
node mem.js sum rollup                   # 7 份日摘要卷成周
```

## 三、参数在哪改

都在 `mem.js` 开头几行：

```js
const BATCH_UP    = 2     // L3/L4/L5 每次最多直接升几个到 L2
const LINK_BUDGET = 10    // 单次联想，牵出事件的被关联权重之和上限
const RECENT_TURNS = 300  // 上下文保留最近多少条原文
const SUM_KEEP = { detail: 7, week: 7, big: 7 }   // 注入：7 日 + 7 周 + 7 周期
const TOP_RATIO   = 0.3   // 每次洗牌取前百分之几
```

改完不用重启，下次跑命令就生效。插件那边（`dsh-memory-inject`）想改要重启 DSH。

## 四、出问题怎么查

| 现象 | 先看这里 |
|---|---|
| 她今天没写摘要 | `<memory-summary>` 里有没有 `## 今天` 那段；`.work/inject_state.json` 的 `lastSeenDate` 是不是今天 |
| 摘要写了但注入没出现 | 文件名对不对——必须是 `26.11.24摘要.json` 这种，跟目录同名 |
| 事件列表是空的 | `长期记忆/*/  _index.json` 在不在；事件本体是 `<事件名>.json`，不带指标 |
| 检索不到明明记过的事 | 关键词没匹配上。去看那条的 `summary` 写没写全 |
| 层级一直不变 | 没跑过 `ev summarize`；或者评定分都打平（全 0），前 30% 等于随机 |

**一个排查习惯**：先造一个事实（跑一次命令、看一眼文件、查一次端口），别靠猜。改十遍写法不如看一眼日志。

## 五、几个容易搞错的点

1. **摘要是她写的，不是引擎写的。** 引擎只落盘。她没写，就是空的——这不是 bug。
2. **注入和压缩是两件事。** 注入每轮都有；压缩只在做周期总结时发生。
3. **分数会变。** 别记文件名里的数字，一切看 `_index.json`。
4. **半丢弃不是删除。** 还在，只是不再自动参与检索和注入。
